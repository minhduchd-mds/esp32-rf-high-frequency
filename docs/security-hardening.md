# Embedded Security Boundary

RF Observatory is a receive-only scientific instrument. The normal development firmware must remain safe to reflash on laboratory boards.

Production deployment should separately evaluate Secure Boot v2, flash encryption release mode, signed OTA, rollback/anti-rollback, protected device identity, certificate rotation and restricted debug/download interfaces.

Do not enable irreversible eFuse-backed production settings in the default CI artifact. A production device should be provisioned through a recorded manufacturing step and should fail closed if the expected provisioned security state is missing.

The HTTPS certificate generated by CI is ephemeral and exists only to prove that the TLS-enabled firmware path compiles. It is not a production credential, device identity or certificate-lifecycle implementation.

A field-station release should record:

- source commit and ESP-IDF version
- firmware and partition-table digests
- receiver/hardware manifest fingerprint
- calibration fingerprint when applicable
- security profile identifier
- TLS/device identity provisioning state
- raw journal retention policy
- health and storage-failure behavior
