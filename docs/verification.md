# Verification — v0.10

## Evidence levels

Keep these separate: host tests, browser tests, firmware compilation, physical hardware measurements.
A passing build or a fake receiver is not a calibrated physical receiver. No military qualification is claimed.

## Repeatable automated gates

- `bash scripts/check.sh`: C++ core, deterministic fault injection at every position of a 512-bin sweep, 1,000 jittered scan cycles, JS model/science/hardware-plan/gateway tests, syntax checks, C++→JSONL→JS.
- `SANITIZE=1 bash scripts/check.sh`: AddressSanitizer/UndefinedBehaviorSanitizer. Restricted local environments may need `ASAN_OPTIONS=detect_leaks=0`; that does not establish leak freedom. CI runs default sanitizer settings.
- `node --test tests/gateway-http.mjs`: real loopback HTTP/SSE, GET-only, origin/Host checks, replay, client limit and fsync raw journal.
- `npm ci && npx playwright install chromium && npm run test:browser`: controls, import/export, invalid-file preservation, fake USB/SSE, mutually exclusive acquisition, calibration/manifest import, raw v2 metadata, sealed v2 download/replay, RFI editor, incompatible/tampered comparison, 1366×768/768×1024/390×844 layout.
- CMake/CTest: normal core and fault-injection executables.
- ESP-IDF 5.4.2 CI: ESP32 and ESP32-S3; S3 compiles HTTPS with ephemeral certificates and read-only GPIO diagnostics enabled.

Check the Actions result for the exact delivered SHA. Test code being present is not evidence that its job passed.

## Limits and commissioning gates

No real RF receiver driver, board-specific pin map, electrical fixture, traceable calibration, environmental qualification or 24/72-hour physical soak result is included.
GPIO inspection reports current configuration only; it does not drive pins or measure their electrical health.
See `esp32s3-validation.md` for board-dependent acceptance work.

Science v2 verifies raw content linkage and deterministic replay. SHA-256 does not authenticate the author. A coherent bundle can be regenerated by someone who controls all inputs.
Legacy science v1 may have a valid checksum but cannot establish reproducible acquisition; comparison is disabled for it.
